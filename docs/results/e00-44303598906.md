# E00 on one RTX 4090 / 首次 E00 实测

On 18 November 2026, the course PTX worker ran on an RTX 4090 in US-IL-1. The 4,096-byte CUDA memory roundtrip passed. All 257 FP32 outputs matched the reference exactly, including the partial last block. The device reported sm_89 and CUDA driver capability 13.2. / RTX 4090 完成显存读写和向量加法，257 个输出最大绝对误差为零，含最后一个不完整线程块。

The original workflow concluded **failure** and the closed ledger records **rejected**. The artifact upload succeeded, then the immediate artifact-by-ID API read returned HTTP 404. A later run-scoped listing returned the artifact. The downloaded ZIP matched the upload digest, its manifest matched the controller journal, and the course validator independently recomputed the numerical result and checked the Pod, image and source identities. / 上传后的即时回执查询返回 404，自动验收失败。事后重新下载原 ZIP，核对压缩包和 manifest 摘要、运行身份并复算通过。

Cleanup issued one DELETE and confirmed absence twice using direct Pod queries and full inventories. The ledger recorded 45 GPU-seconds and a conservative USD 0.021138 estimate including allowances. The retained reservation is USD 0.1585 and 600 GPU-seconds. / 两轮查询确认 Pod 已删除。账本估算费用含预留杂费，实际扣费以供应商账单为准。
