# E02 · Hosted RMSNorm forward / 单卡 RMSNorm 前向验收

Run **Course E02 RMSNorm GPU** manually on main with `confirm_paid` enabled. One attempt reserves up to 20 allocated GPU-minutes. The E02 ledger allows US$3 and 180 GPU-minutes cumulatively. The 30 GB temporary disk allowance defaults to 5,000 micro-USD/hour and the request/transfer allowance to 10,000 micro-USD per attempt. The controller checks inventory, the live quote, actual billed rate and remaining reservations before proceeding.

在 main 手动触发。优先 RTX 4090，各组共用一个 Pod。控制器在预留额度后只提交一次创建请求，正常退出和独立恢复工作流均按所有权核查清理。收据与两次删除复查记录在课程账本中。

The worker checks both forward implementations against the FP64 reference. Download the artifact named for the owning run. It contains the summary with input/weight hashes, 20 Chrome traces, the manifest and transfer receipt. CPU replay checks file hashes, runtime identity, source hashes, matched inputs for the two strides, kernel counts, tolerance ratios, seven timing samples and each median. Compare rows 1 and 512 at width 1024 for each dtype.

验收产物包含 10 组输入、20 份 trace 和单独采集的计时样本。查看各组 eager 与 fused 的延迟比，核对分块尾部和隔列输入的误差；性能变慢也应记录。Softmax 和反向算子另行验收。
