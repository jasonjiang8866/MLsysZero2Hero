# E01 · Hosted trace validation / 托管 trace 验收

The manual **Course E01 GPU traces** workflow runs all four cases on one GPU. Use the main branch and enable `confirm_paid`. The course ledger reserves up to 20 GPU-minutes per attempt, including provisioning and cleanup. E01 has a cumulative US$3 and 150 GPU-minute allowance. The defaults reserve 5,000 micro-USD/hour for the 30 GB temporary disk and 10,000 micro-USD for extras. The controller checks the live compute quote, available capacity, billed rate and both budgets.

手动选择 main 和 `confirm_paid`。四组对照共用一张卡，先查库存和报价，按 E01 子额度记账；单次预留含启动与清理的 20 GPU 分钟。镜像固定到 PyTorch 2.9.0 / CUDA 12.8 的公开 digest。Pod 从当前提交直接接收实验代码，只使用临时磁盘。

Download the E01 artifact from the owning run. It includes four Chrome traces, four unprofiled timing samples per case in `summary.json`, and runtime identity plus file hashes in `manifest.json`. The collector recomputes kernel intervals, checks case annotations and output bytes against an independent CPU-generated SHA-256, and verifies the received files. Check the owner's cleanup step or recovery journal for two independent absence checks.

诊断时对比 baseline 与 small_launches 的 kernel 数，用 host_cpu 与 io_wait 的线程 CPU 时间解释为什么相似的 GPU 空隙可能有不同原因。归档校验及清理记录见对应 Actions 运行。若任一组缺失 CUDA 活动或输出不一致，本次不能通过验收。
